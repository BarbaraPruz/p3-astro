# P3 website

P3 website built with Astro.

The folder structure follows the basic Astro setup:
- root: readme, package.json
- src: components (small pieces including reusable items), layouts (page layouts), pages (specific pages)

## Development Setup

- install dependencies `npm i`
- run application `npm run dev` Application will be available at localhost:4321
